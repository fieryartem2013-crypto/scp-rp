# SCP RP | DarkRP (SCP_SERVER v1.0.0)

**Версия:** 1.0.0  •  **Имя в меню:** «SCP RP | DarkRP»  •  **Папка:** `darkrp`
**База:** sandbox (DarkRP не требуется)
**Язык:** русский

Серьёзный SCP RP фреймворк: архитектура Helix (фракции, департаменты, вайтлисты, персонажи, хуки схемы) + доступность DarkRP (F4-меню, простая установка).

---

## Установка

### Шаг 1. Распакуй архив
`SCP_SERVER_v1.0.0.zip` распакуй **внутрь папки `garrysmod`**.
Должно получиться ровно так (проверь, чтобы не было двойной папки):

```
.../Steam/steamapps/common/GarrysMod/garrysmod/gamemodes/darkrp/gamemode.info
.../Steam/steamapps/common/GarrysMod/garrysmod/gamemodes/darkrp/gamemode/shared.lua
```

⚠️ Частая ошибка: получается `garrysmod/gamemodes/gamemodes/darkrp` — тогда удали лишнюю папку.

### Шаг 2. Найди в меню
New Game → справа список гейммодов → ищи **«SCP RP | DarkRP»**
(или введи в поиск `scp` / `darkrp`).

### Шаг 3. Если не видно в списке
1. Убедись, что файл `gamemode.info` лежит ровно по пути выше.
2. Перезапусти GMod полностью (не только меню).
3. Проверь консоль (`~`) на ошибки загрузки.
4. Если ставил в `garrysmod/addons/` — перенеси в `garrysmod/gamemodes/`.

### Сервер
```bash
./srcds_run -game garrysmod +map rp_downtown_v4c_v2 +gamemode darkrp -maxplayers 24
```
Папка гейммода остаётся `darkrp` (это техническое имя для консоли),
а в меню он отображается как «SCP RP | DarkRP».

## ⚠️ Важно про структуру файлов

GMod ищет точки входа строго по именам:
- сервер → `gamemodes/darkrp/gamemode/init.lua`
- клиент → `gamemodes/darkrp/gamemode/cl_init.lua`
- общее  → `gamemodes/darkrp/gamemode/shared.lua`

Если переименовать `init.lua` во что-то другое — появится ошибка
«Couldn't include file 'gamemode/init.lua'» и гейммод не загрузится.

**Папка `framework/` обязана лежать внутри `gamemode/`**, а не в `lua/`.
`include()` в GMod резолвит путь относительно папки вызывающего файла,
поэтому `include("framework/sh_config.lua")` из `gamemode/shared.lua` ищет
`gamemode/framework/sh_config.lua`. Если положить framework в `lua/`,
фреймворк молча не загрузится и хуки упадут с «attempt to index global 'SCPF'».

## Настройка

Все цифры в `gamemode/framework/sh_config.lua`:
- Деньги, зарплата, арест, брич, инвентарь, уровни доступа

Вайтлисты: `data/scpf/whitelists/<faction|jobid>.txt` (SteamID64 по строке)
Спавны: `data/scpf/spawns.txt` (JSON, админ `/setspawn`)
